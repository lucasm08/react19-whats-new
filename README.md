# React 19 - What's New

Presentation and Demos of the new stuff in React 19

## Overview

This repository contains presentations and demos showcasing the exciting new features introduced in React 19. Whether you're a developer looking to stay up-to-date with the latest React developments or preparing for a presentation on React 19, this repository has you covered.

## What's New in React 19

React 19 brings several groundbreaking features and improvements:

### Key Features
- **React Compiler** - Automatic optimization without manual memoization
- **Actions** - Simplifying form handling and async state management  
- **New Hooks** - `use()`, `useActionState()`, `useFormStatus()`, and `useOptimistic()`
- **Document Metadata** - Native support for `<title>`, `<meta>`, and `<link>` tags
- **Web Components** - Better integration with custom elements
- **Asset Loading** - Built-in support for preloading resources

### Breaking Changes
- Stricter hydration errors
- Removed deprecated features from React 18
- Updated TypeScript definitions
